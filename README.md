# Storage Estimator

## Purpose
A small Python program that estimates how much storage a set of files needs,
given the number of files and their average size. Built for CS-117
Introduction to ICT (Lab 10) and version-controlled with Git in Lab 11.

## How to run
Requires Python 3.

```
python storage_estimator.py
```

## Example
```
Number of files: 250
Average file size (KB): 800
Total storage: 204,800,000 bytes
             = 200,000.00 KB
             = 195.31 MB
```
